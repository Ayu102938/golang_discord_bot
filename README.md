# Discord Bot コマンド説明書

このBotは、あなたのスケジュールを管理し、指定した時間にDiscordで通知を送るリマインダーBotです。
全ての操作は**スラッシュコマンド（/）**で行います。

## 利用可能なコマンド一覧

### 1. 予定の登録
**コマンド:** `/timetable`

新しい予定を登録するためのモードを開始します。Botの指示に従ってチャットで情報を入力してください。
（※将来のアップデートでフォーム入力に変更される予定です）

**登録手順:**
1. `/timetable` と入力して実行します。
2. **タイトル**を入力してください（例: `会議`, `燃えるゴミ`）。
3. **日付**を `yyyy/mm/dd` 形式で入力してください（例: `2025/12/31`）。
4. **メモ**を入力してください（不要な場合は「なし」）。
5. **通知タイミング**を入力してください。
    - `1d`: 1日前
    - `12h`: 12時間前
    - `0`: 当日（朝9時を基準に計算されます）

---

### 2. 予定の一覧表示
**コマンド:** `/list`

現在登録されているあなたの予定を一覧表示します。
各予定には `1.`, `2.` などの番号が振られており、削除時に使用します。

---

### 3. 予定の削除
**コマンド:** `/delete index:[番号]`

指定した番号の予定を削除します。番号は `/list` で確認してください。

**使用例:**
- `/delete index:1` : リストの1番目の予定を削除します。

---

### 4. 通知先チャンネルの設定
**コマンド:** `/setch`

リマインド通知を受け取るチャンネルを設定します。**予定を登録する前に、サーバーごとに一度設定する必要があります。**
設定がない場合は、BotからDM（ダイレクトメッセージ）で通知が届きます。

**設定手順:**
1. 通知を受け取りたいチャンネルで `/setch` と入力し実行します。
2. 対象のチャンネルをメンション形式（例: `#general`）で入力してください。

---

### 5. リマインド動作テスト
**コマンド:** `/testremind`

強制的にリマインドチェック処理を実行します。通常は1分ごとに自動実行されますが、すぐに通知を確認したい場合に使用します。
