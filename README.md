# Discord Timetable Bot

スケジュール管理とリマインド通知を行うDiscord Botです。
スラッシュコマンドと入力フォーム（モーダル）を使った直感的な操作が可能です。

## 機能概要

- **予定の登録**: ポップアップフォームでタイトル、日付、メモ、リマインド時期を簡単入力。
- **リマインド通知**: 指定した時期にチャンネルまたはDMで通知。
- **一覧確認**: 自分の登録した予定を一覧表示。
- **削除**: 完了した予定を削除。
- **排他制御**: 高速かつ安全なデータ処理（v2.0以降）。

## 使い方

### 1. Botの準備
1. `discord_bot.exe` を起動します。
2. 初回起動時、同ディレクトリに `timetable.csv` と `channels.csv` が自動作成されます。

### 2. 初期設定
Botをサーバーに追加したら、まず通知先のチャンネルを設定してください。

**コマンド:** `/setch`
- Botが「通知先のチャンネルを...」と応答したら、チャット欄でチャンネルをメンションしてください（例: `#general`）。

### 3. スケジュールの登録
**コマンド:** `/timetable`
- 入力フォームが表示されます。
    - **タイトル**: 予定の名前（例: 会議, 燃えるゴミ）
    - **日付**: `2026/01/24` のような形式
    - **メモ**: 補足（任意）
    - **リマインド時期**: 
        - `1d` (1日前)
        - `12h` (12時間前)
        - `30m` (30分前)
        - `0` (当日朝9時)

### 4. 確認と削除
**コマンド:** `/list`
- 登録済みの予定一覧を表示します。各予定の左側に番号が表示されます。

**コマンド:** `/delete`
- 削除したい予定の番号を指定して実行します（例: `/delete index:1`）。

### 5. テスト用
**コマンド:** `/testremind`
- 強制的にリマインド処理を実行し、通知テストを行います。

- 言語: Go 1.23+
